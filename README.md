# kannji

ブラウザ向け漢字バトルゲーム。名称は仮です。
仕様は [docs/specification.md](docs/specification.md) を参照してください。

## 現在の状態

アクション版：円形闘技場で四文字を動かし、突進攻撃・回転回避で戦います。ガチャのレアリティ保持・加点移動・効果音・結果表示も利用できます。
ホームから全250字の一覧を閲覧でき、ガチャで「引く」→「書く／消す」を操作できます。
4文字取得または10回目の採否で終了し、不足分は数字「1」で補填します。
4文字が確定すると自動で試合へ進み、ポイント集計→能力表示→戦闘開始ボタン→手動アクション→リザルトと進みます。
「もう一度書く」でガチャから再戦できます。

以前の3D試作は http://127.0.0.1:5173/kannji/?prototype で確認できます。
ドラッグで4文字をまとめて回転でき、正面・斜めの表示を切り替えられます。

## 開発（Windows / Git Bash）

検証環境：Node.js v24.11.1 / npm 11.6.2。

```bash
cd /c/dev/games/kannji
npm ci
npm run dev
```

ターミナルに表示されたURL（通常は http://127.0.0.1:5173/kannji/ ）を開きます。
終了は Ctrl+C。ポートが使用中なら、Viteが表示するURLを使ってください。

```bash
# TypeScriptの確認と公開用ビルド
npm run build

# ゲームルールのテスト（Node.js 24推奨）
npm test

# ビルド結果のローカル確認
npm run preview
```

公開用ファイルは `dist/` に生成されます。
GitHub Pages向けのbaseは `/kannji/` に設定しています。
Pages用Actionsと公開設定は後の区切りで追加します。

## フォント

ユーザー提供の Noto Serif JP Bold を使用しています。
著作権表示とSIL Open Font License 1.1は `public/fonts/OFL.txt` に同梱しています。
ライセンスはビルド時にも `dist/fonts/` へコピーされます。

画面表示では必要な文字だけを抽出した `public/fonts/kannji-ui-bold.ttf`
（派生フォント名：Kannji UI）を使用します。元の約8MBから約289KBへ縮小しました。
元のフォントは輪郭の再生成用に保持し、画面からは読み込みません。派生フォントもOFL 1.1です。
UIの日本語を追加・変更した場合は、Pythonとfonttoolsで再生成してください。

```bash
python scripts/subset-ui-font.py
```

生成済みフォントを保存するため、通常の開発・ビルドにはPythonは不要です。

3D表示には、収録250字と数字「1」の輪郭だけを抽出した
`public/fonts/kannji-outline.typeface.json`（改変フォント名：Kannji Outline）を使用します。
同じOFLライセンスを適用します。外部CDNへの依存はありません。
文字の厚みは0.16、ベベルなしの初期設定です。形状を文字ごとにキャッシュし、4文字を同じ親にまとめます。

```bash
# 全251文字の立体化と、田・目の空洞／画線の検証
node scripts/check-font.mjs
```

輪郭データは生成済みのため、通常の開発・ビルドにPythonは不要です。
フォントを変更して再生成する場合だけ、Pythonとfonttoolsが必要です。

```bash
python -m pip install fonttools
python scripts/convert-font.py
node scripts/check-font.mjs
```

## ゲームルールと調整箇所

- `src/data/kanji.ts`：250字と所属グループ。ガチャ・敵の抽選は全字均等、重複あり。
- `src/data/groups.ts`：7グループの文字点範囲と3次元ベクトル。
- `src/data/rules.ts`：抽選回数・補填得点・組み合わせ点の倍率／係数／上限。
- `src/data/rarities.ts`：共通レアリティ抽選の重み・固定加算点・演出色。
- `src/data/combat.ts`：7グループの能力配分・係数・倍率。
- `src/data/action.ts`：円の半径・移動速度・攻撃／回避時間・無敵時間・制限時間・能力圧縮。
- `src/data/camera.ts`：カメラの距離・高さ・追従速度・中心付近の安定範囲。
- `src/data/comments.ts`：勝利・敗北・引き分けコメントと補填時の最優先コメント。
- `src/data/presentation.ts`：ガチャ・加点・決着の演出時間。
- `src/data/sound.ts`：Web Audioで生成する効果音の音量・同時発音数。

数値は初期設定です。アクションの仕様は第18節、最新のカメラ・背景・回転回避は第22節を参照してください。
ルールの変更後は `npm test` と `npm run build` で確認します。
初期値の期待値を検証するテストは、意図した数値変更に合わせて更新してください。

`createGacha` → `draw` → `decide` → `getTeam` の順に4文字を確定します。
採否未決定の再抽選や完了後の抽選はエラーになります。
`createBattle` は試合開始時に一度呼び、得点・能力・背景4字を画面側で保持します。
再描画や加点演出のたびに呼び直しません。勝敗は入力と命中判定によって戦闘中に決まり、終了時にコメントを選びます。
数字「1」が含まれる場合は通常加点を行わず、開始時から合計1点と理由を表示し、体力・攻撃力・防御力をすべて1にします。

## 画面確認（区切り4）

1. ホームの「漢字一覧」で7分類・全250字を確認し、「ホーム」で戻る。
2. 「書き始める」→「引く」→「書く／消す」。抽選中はボタンが無効になる。
3. 4字を採用すると取得順で確定し、残り回数があっても抽選を終了して試合へ進む。
4. 10回すべて「消す」で「1111」と試合開始時から合計1点になる理由を確認する。
5. 「もう一度書く」、またはホームに戻って開始すると、取得0字・残り10回へ戻る。
6. 抽選中にホームに戻り、新しい画面へ前の抽選結果が出ないことを確認する。

PCは取得文字と抽選を左右に、幅700px以下では縦に配置します。
スマホ縦390×844とPC1366×900で横方向のはみ出しがないことを確認済みです。
端末の「視差効果を減らす」などの設定時は、ガチャの動きを省略します。

## 試合確認（区切り5）

- 敵の4文字と得点は左上、自分は右下。文字そのものを押し出した4字一体のモデルが浮遊します。
- 左から文字点4回→組み合わせ点→左からレアリティ点4回。文字付近から出たポイントが総ポイント欄へ到着してから加算します。組み合わせ点は4文字の中央から出ます。
- レアリティの加点時はN白／C緑／R銅／SR金／UR虹の色で演出します。
- 集計後に能力を表示。「戦闘開始」から手動で移動・攻撃・回転回避を行います。命中すると火花・衝撃波・体力更新。敵の体力を0にすると勝利です。
- 数字「1」を含む側は加点せず、最初から最後まで1点。結果コメントは「もはや漢字じゃない」です。
- 試合・結果の双方に「体力:現在値/最大値」（緑）、「攻撃力:数値」（赤）、「防御力:数値」（青）を表示します。リザルトにも双方の4文字・ポイント・レアリティを表示します。
- 試合途中の「ホーム」は加点待ち・描画を停止します。戻った後に古い試合がリザルトへ遷移しないことを確認してください。
- 3D表示に失敗した場合は試合を止め、ホームへ戻れる案内を表示します。動きを減らす設定では浮遊・回転の見た目・火花などを省略します。移動・回避判定は同じです。

初期演出時間はガチャ600ms、試合導入900ms、ポイント移動600ms＋到着後420ms、能力表示1600ms、決着1600msです。攻撃・回避の時間は `src/data/action.ts` で調整します。
3Dフォントの読み込みは12秒で打ち切り、失敗時は文字と得点で進行します。

## 改訂後の計算と音

通常ポイントは100〜99,999点。文字点は各25〜12,000、組み合わせ点は0〜19,999、レアリティ点はN:0／C:500／R:2,000／SR:4,000／UR:8,000の初期値です。
ガチャで決まったレアリティを取得文字に保持し、試合で再抽選しません。敵も4文字とレアリティを一度だけ抽選します。

能力は合計点をグループ構成の平均配分で分け、体力8・攻撃力2・防御力1.6の係数を掛けます。その後、体力は `400 + √元能力 × 1.4`、攻撃力は `50 + √元能力 × 0.6`、防御力は `15 + √元能力 × 0.3` へ圧縮します。
最後に能力ごとに独立した1.000〜2.000倍（0.001刻み、両端含む）を掛けて四捨五入します。
ダメージは `攻撃力 × 攻撃力 ÷ (攻撃力 + 相手の防御力)` を四捨五入し、最低1です。
制限時間は90秒。時間切れは残り体力の割合で勝敗を判定し、同率なら引き分けです。双方が同時に体力0になった場合も引き分けです。

効果音はWeb Audioの合成音で、外部素材や通信は不要です。最初の操作で音声を有効化し、画面上部の「効果音:入／切」で切り替えます。
ガチャ・採用／破棄・ポイント到着・打撃・勝利／敗北ごとの音を用意しています。音量は `src/data/sound.ts` で調整できます。

## アクション操作と背景

- PC：WASD／方向キーで移動、J／Spaceで攻撃、K／Shiftで回転回避、Escで一時停止／再開。
- スマホ：左の移動スティック、右の攻撃／回転回避ボタン。
- 静止中の回避は敵から離れる方向。移動中はその方向へ一回転してダッシュ。
- 回避は文字のワールドY軸で横方向に回転し、側面と厚みが見えます。無敵時間・終了後の隙・再使用待ち時間があります。予備動作中の敵の足元が点滅します。
- 準備が整ったら「戦闘開始」。一時停止／再開ボタンを備え、タブが非表示の間は戦闘時間と判定を止めます。
- 円の境界を越えて移動できません。攻撃は方向と間合いで当たり、1回の突進で同じ敵に複数回は当たりません。
- 背景は一覧250字から重複なしで4字を選び、1文字ずつ別の墨文字として配置。薄い墨・漂い・にじみ風の透過変化を使い、試合中は同じ4字を保持します。

カメラは水平面で「闘技場中心 → プレイヤー → カメラ」の順に並び、常に闘技場中心を正面にします。プレイヤーが中心を越えると、カメラは滑らかに反対側へ回り込みます。切り替え中は一直線の配置へ追従します。カメラが回転した後も、W／上入力は画面の奥、D／右入力は画面の右へ移動します。
中心半径1.4以内では直前の方位を保ち、細かな反転を防ぎます。最大角速度は6rad/秒（以前の1.6rad/秒から増加）、追従係数12です。戦闘時はプレイヤー後方6・文字より上3から中心の高さ1を注視します。集計中は全景を表示します。
墨文字はカメラに貼り付けず、高さ・距離・向きの異なるワールド空間内の4枚の面に配置します。土台・周囲の柱・奥の霧と、周回時の視差・遠近・遮蔽で空間の奥行きを表現します。

初期値は攻撃予備動作0.24秒、突進0.20秒、後隙0.34秒。回避は0.48秒、うち0.04〜0.35秒が無敵、待ち時間1.35秒です。
実機でのスティック操作・難易度・音量の最終調整は未確認です。
